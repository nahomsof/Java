# Java

## Runnable Project: Task Manager

Start with [task-manager/README.md](task-manager/README.md) for a complete Java command-line app with persistent tasks and tests. It needs JDK 11+ and no external libraries. Existing exercises remain unchanged.

```sh
cd task-manager
javac TaskManager.java TaskManagerTest.java
java TaskManager add "Learn Java"
java TaskManager list
java TaskManagerTest
```
